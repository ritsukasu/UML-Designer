How it works

Ask your agent.
One file comes back.

The agent writes a small typed diagram.json. uml-designer checks it, lays it out and delivers a viewer you can open anywhere.

  1. 01

    Ask.

    Ask your coding agent for a class or use-case diagram of a module, a domain or a whole codebase.

  2. 02

    It writes JSON.

    A small typed diagram.json: classes, or actors and use cases, plus relations and views. No coordinates.

  3. 03

    uml-designer checks it.

    validate names each problem with a code and the allowed fixes. The agent repairs what is named.

  4. 04

    One file comes back.

    deliver lays the diagram out and writes one self-contained HTML viewer.
